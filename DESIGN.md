# JATIN — THE SERIES · Design Constitution

## Identity
- Concept: an original cinematic portfolio, inspired by streaming-platform storytelling, not a reproduction of another portfolio's unlicensed implementation.
- Hero: **dark cinematic portrait** under a restrained **studio spotlight**.
- Palette: Obsidian #0B0D11, Champagne Gold #D6B57A, Ivory #F5F1EA, Slate #777B86.
- Typography: Bebas Neue for display, Manrope for UI and narrative, JetBrains Mono for technical labels.
- Motion language: purposeful premium motion, restrained 3D depth; avoid constant animation and excessive glow.

## Information architecture
1. Opening title sequence (skippable, ~5 seconds)
2. Explore / Recruiter / Developer profile choice (changes order, never suppresses actual content)
3. Cinematic hero with image continuity
4. About / Journey / Original project posters / Skills / Highlights / Resume
5. To Be Continued — contact CTA

## Locked experience rules
- Desktop: large editorial composition and side-scrolling Originals posters.
- Mobile: stacked legible hero, swipeable project rail.
- Posters: individual thematic cinematic designs; click opens detailed fullscreen project modal.
- Resume action is disabled until a real PDF is supplied.
- No invented awards, metrics, employers, testimonials, certifications or unsupported project claims.
- Honour prefers-reduced-motion and support keyboard navigation, Escape, and readable contrast.
- Actual photo is copied from the existing README repository; original remains unchanged.

## Safety boundary
Never mutate jatin45ppandey-design/jatin45ppandey-design or its existing deployed portfolio.
Implement changes in the dedicated Portfolio-2 repository (or rename it to Jatin-The-Series when owner chooses).

## Codex editing guidance
Use src/data/portfolio.ts as the factual source of truth. Make targeted revisions; preserve theme tokens, editorial spacing, font hierarchy, section priorities and accessibility. Commit in small increments and test with npm run build.
