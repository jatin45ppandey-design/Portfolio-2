# JATIN — THE SERIES

**A cinematic portfolio for Jatin Pandey** — backend-focused developer building practical software.

Independent React + TypeScript + Vite + Framer Motion implementation. Uses a streaming-inspired storytelling concept with an **Obsidian × Champagne Gold** identity.

## Getting started

Requirements: Node.js 20+.

    npm install
    npm run dev

Production check:

    npm run build
    npm run preview

## Experience

- Skippable studio intro and cinematic portrait hero
- Explore / Recruiter / Developer profiles (same facts, different section order)
- Cinematic project poster gallery with expanded case studies
- Journey episodes, evidence-based skills, genuine build highlights
- Resume section that safely prompts for a PDF rather than linking to a nonexistent document
- Keyboard support, reduced motion, mobile navigation and responsive gallery

## Content

Update **src/data/portfolio.ts** for projects, skills, biography, contact links and resume PDF. View **DESIGN.md** for immutable design principles and future Codex guidance.

### Assets

The portrait at public/images/jatin-profile.jpg is a copy of the photograph already present in the GitHub profile README repository (original remains untouched). Replace the portrait with a higher-resolution cutout or studio photo as desired. Project posters are custom CSS illustrations (no unauthorized third-party graphics).

To enable the resume, add the actual document to public/resume/Jatin_Pandey_Resume.pdf and set profile.resumePdf to '/resume/Jatin_Pandey_Resume.pdf'.
